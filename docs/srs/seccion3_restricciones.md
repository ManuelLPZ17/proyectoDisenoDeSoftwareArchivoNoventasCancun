# Sección 3: Restricciones

Las restricciones representan limitaciones de diseño y operación impuestas por factores técnicos, legales o de integración que el equipo no eligió libremente, sino que rigen de forma obligatoria sobre el desarrollo del sistema:

1. **RST-01 (Plataforma y compatibilidad de navegación):** El sistema debe operar como una aplicación web accesible mediante navegadores web modernos estándar (Google Chrome versión $\ge 110$, Mozilla Firefox versión $\ge 115$, Apple Safari versión $\ge 16$ y Microsoft Edge versión $\ge 110$) con soporte para estándares HTML5, CSS3, WebGL y JavaScript ECMAScript 2022, tanto en resoluciones de escritorio ($\ge 1280 \times 720\text{ px}$) como en dispositivos móviles y tabletas ($\ge 375 \times 667\text{ px}$).
2. **RST-02 (Proveedor cartográfico obligatorio):** La visualización geográfica y la renderización de mapas debe implementarse estrictamente mediante el servicio externo **Google Maps JavaScript API**, utilizando una clave de API (*API Key*) autenticada y aplicando personalización visual mediante estilos de nube o JSON de estilización.
3. **RST-03 (Cumplimiento normativo de protección de datos personales):** El manejo y almacenamiento de datos de contacto recabados en los formularios de propuesta (nombres y correos electrónicos opcionales) debe apegarse rigurosamente a lo dispuesto en la **Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP)** de México, garantizando aviso de privacidad visible y prohibiendo la transferencia no consentida de información a terceros.
4. **RST-04 (Formatos estándar de archivos):** Para garantizar portabilidad y preservación digital sin requerir software propietario adicional por parte del usuario, los recursos multimedia admitidos se restringen exclusivamente a formatos de amplia compatibilidad web: imágenes en `.jpg`, `.png` y `.webp`; documentos en `.pdf`; y paquetes comprimidos en `.zip`.
